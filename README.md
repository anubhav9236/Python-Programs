# 🐍 Python Programs

A collection of basic Python programs created for **learning, practice, and understanding fundamental programming concepts**. This repository contains beginner-friendly programs covering mathematical operations, number-based problems, strings, dates, exception handling, and basic data structures.

## 📚 Programs Included

| Program                 | Description                                                 |
| ----------------------- | ----------------------------------------------------------- |
| `hello.py`              | Basic Hello World program                                   |
| `Armstrong.py`          | Checks whether a number is an Armstrong number              |
| `Factorial_number.py`   | Calculates the factorial of a number                        |
| `Fibonaci_Series.py`    | Generates the Fibonacci series                              |
| `Palindrome.py`         | Checks whether a number/string is a palindrome              |
| `Leap_year.py`          | Checks whether a year is a leap year                        |
| `DOB.py`                | Works with Date of Birth and date-related operations        |
| `Reverse_Slicing.py`    | Demonstrates reversing using Python slicing                 |
| `exception_handling.py` | Demonstrates exception handling using `try`, `except`, etc. |
| `Circular_Queue.cpp`    | Implementation of a Circular Queue                          |
| `Circular_Queue.exe`    | Executable file of the Circular Queue program               |

## 🚀 How to Run

### Python Programs

Make sure Python is installed on your system.

```bash
python filename.py
```

For example:

```bash
python Armstrong.py
```

### C++ Program

Compile the Circular Queue program using:

```bash
g++ Circular_Queue.cpp -o Circular_Queue
```

Then run:

```bash
./Circular_Queue
```
